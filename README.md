# SIGNAL — Data Intelligence Studio

Explore data. Discover patterns. Understand more.

SIGNAL is a browser-based data exploration platform designed to make CSV analysis more accessible through interactive summaries, filtering, and visualisations.

Live Demo

[Launch SIGNAL](https://csvg.vercel.app⁠)

Features

- CSV data import
- Dataset summaries
- Searchable and sortable tables
- Interactive data visualisations
- Metric selection
- Clean, responsive interface

Technology

- HTML
- CSS
- JavaScript
- Browser-based data processing

Project Status

This repository contains an independent reconstruction of the SIGNAL project. It is not the original deployment source code.
